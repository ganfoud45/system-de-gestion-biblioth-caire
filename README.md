Système de Gestion Bibliothécaire

Application Java pour la gestion complète d'une bibliothèque : livres, membres, emprunts et retours.

Aperçu du projet : 

Ce projet est une application Java de gestion bibliothécaire permettant à un administrateur (bibliothécaire) 
de gérer le catalogue de livres, les membres inscrits ainsi que les opérations d'emprunt et de retour. 
L'objectif est de moderniser et d'automatiser la gestion d'une bibliothèque traditionnell

Fonctionnalités : 

--> Gestion des livres :
.Ajouter, modifier et supprimer un livre du catalogue
.Rechercher un document par ces notions spécifiques 
.Consulter la disponibilité d'un livre (disponible / emprunté)

-->Gestion des adhérents :
.Ajouter ,modifier et supprimer un adhérent
.Consulter la liste des adhérents de la bibliothèque
.Consulter l'historique des emprunts d'un adhérent

-->Gestion des emprunts :
.Ajouter, modifier et supprimer un emprunt 
.Enregistrer un emprunt (avec date de début et date de retour prévue)
.Enregistrer le retour d'un livre


Vues : 

1.Bibliothécaire : gestion des documents, gestion des adhérents,gestion gestion des prets
2.Adhérent       : Recherche un document , emprunter un document , consulter la liste des documents , retourner le document emprunté



Technologies utilisées :

 java JDK 25                --> Langage principal
 Maven/Gradle           --> Gestion des dépendances et build
 MySQL                  --> Base de donnée
 JDBC/Hibernate         --> Accès et mapping des données
 JavaFX/SWING           --> interface graphique
